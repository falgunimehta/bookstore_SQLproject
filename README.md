# bookstore_SQL_Project


This project focuses on analyzing a bookstore database using SQL. It involves retrieving, filtering, and analyzing data from three related tables to answer basic and advanced business question. 

The objective is to practice SQL queries and gain insights into book inventory, customer information, and sales transactions.

The project contains three CSV datasets:

1.Books

Book_Id= unique ID of each book

Title= Book title

Author= Name of the author

Genre= Book category

Published_year= Year of publication

Price= Price of the the book

Stock= available stock quantity

2.Customers

Customer_ID= Unique ID of each customer

Name= Customer Name

Email= Customer email address

Phone= Customer phone number

City= customer's city

Country= Customer's country

3.Orders

Order_ID= Unique ID of each order

Customer_ID= Customer who placed the order

Book_ID= Book purchased 

Order_date= date of the order

Quantity= Number of books ordered

Total_amount= Total order amount
